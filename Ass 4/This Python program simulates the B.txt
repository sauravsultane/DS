Logic of This Code

This program implements the Berkeley Clock Synchronization Algorithm.

The main logic is:

Make all computers in a network show nearly the same time.

Problem

In distributed systems:

every computer has its own clock,
clocks may run faster/slower,
time becomes different on each machine.

Example:

Node	Time
0	100
1	102
2	98.5
3	101.2

These clocks are not synchronized.

Main Logic of Berkeley Algorithm

The algorithm works in 5 main steps:

1. Select Coordinator
2. Collect Times
3. Calculate Average Time
4. Compute Offsets
5. Adjust All Clocks
Step 1: Select Coordinator
Coordinator(0, 100.0)

One node becomes coordinator.

Coordinator controls synchronization.

In this program:

Node 0 = Coordinator
Step 2: Collect Clock Times

Coordinator polls every node.

for node in nodes:

It asks:

"What is your current clock time?"
Example
Node	Time
1	102
2	98.5
3	101.2
Step 3: Simulate Network Delay
delay = random.uniform(0.1, 0.5)

Real networks have communication delay.

The code simulates this.

Example:

message takes 0.4 sec to travel.
Delay Adjustment
node_time = node.get_time() + delay / 2

Assumes:

delay is equal both directions.

So only half delay is added.

Step 4: Calculate Time Difference
times[node.node_id] = node_time - self.clock_time

Coordinator compares:

node time
coordinator time
Example

Coordinator:

100 sec

Node 1:

102 sec

Difference:

102 - 100 = +2 sec

Meaning:

Node 1 is 2 seconds ahead.
Step 5: Calculate Average Time
average_offset = sum(times.values()) / len(times)

All differences are averaged.

Example
Node	Difference
0	0
1	+2
2	-1.5
3	+1
4	-0.2

Average:

(0 + 2 -1.5 +1 -0.2)/5
= 0.26 sec

This becomes synchronization reference.

Step 6: Calculate Offset
offset = average_offset - times[node.node_id]

Offset means:

how much each clock must change.
Example

Node 1 difference:

+2 sec

Average:

0.26 sec

Offset:

0.26 - 2
= -1.74 sec

Meaning:

decrease Node 1 clock by 1.74 sec.
Another Example

Node 2 difference:

-1.5 sec

Offset:

0.26 - (-1.5)
= +1.76 sec

Meaning:

increase Node 2 clock by 1.76 sec.
Step 7: Adjust Clocks
node.adjust_time(offset)

Clock values are updated.

Final Result

All clocks become nearly equal.

Example:

Node	Final Time
0	100.30
1	100.30
2	100.30
3	100.30
Core Logic in One Line
Collect all clock times → Find average → Adjust clocks toward average
