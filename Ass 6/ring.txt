class RingAlgorithm:


Creates a class named RingAlgorithm.


This class contains all functions and data for Ring Election Algorithm.



Constructor
    def __init__(self, processes):


Constructor function.


Runs automatically when object is created.


processes contains list of process IDs.


Example:
[1, 2, 3, 4]

        self.processes = sorted(processes)


Sorts process IDs in ascending order.


Example:
sorted([4,2,1,3])
Output:
[1,2,3,4]
Stored in:
self.processes

        self.ring = self.processes[:]


Creates a copy of process list.


This represents logical ring structure.


Ring becomes:
1 → 2 → 3 → 4 → back to 1

        self.coordinator = None


Initially no coordinator selected.


None means empty value.



Alive Check Function
    def is_alive(self, process_id):


Function to check whether process is active.



        return process_id in self.ring


Returns True if process exists in ring.


Otherwise returns False.


Example:
3 in [1,2,3,4]
Output:
True

Election Function
    def hold_election(self, initiator):


Starts election process.


initiator = process starting election.


Example:
initiator = 2

        print(f"Process {initiator} starts election.")


Prints election start message.


Output:
Process 2 starts election.

Election List
        election_list = [initiator]


Creates list to store participating processes.


Initially:
[2]

Find Position of Initiator
        current_index = self.ring.index(initiator)


Finds index position of initiator inside ring.


Example:
self.ring = [1,2,3,4]
Position of 2:
1
So:
current_index = 1

Infinite Loop
        while True:


Loop continues until manually stopped using break.



Move to Next Process
            current_index = (current_index + 1) % len(self.ring)
This line moves to next process in circular way.
Example:
len(self.ring) = 4
If current index:
1
Then:
(1+1)%4 = 2
Moves to next process.

Why % is used?
% keeps ring circular.
Example:
(3+1)%4 = 0
So after process 4,
it returns back to process 1.
This creates circular ring.

Get Next Process
            next_process = self.ring[current_index]


Gets next process from ring.


Example:
self.ring[2] = 3
So:
next_process = 3

Stop Condition
            if next_process == initiator:                break


If message comes back to starting process,
election is complete.


Loop stops.


Example:
2 → 3 → 4 → 1 → 2
When reaches 2 again:


Stop loop.



Print Election Message
            print(f"Election message from {election_list[-1]} to {next_process}")


Prints message passing.


election_list[-1]
means last process in list.
Example:
Election message from 2 to 3

Add Process to Election List
            election_list.append(next_process)


Adds next process into election list.


Example flow:
[2][2,3][2,3,4][2,3,4,1]

Select Winner
        winner = max(election_list)


Finds highest process ID.


Example:
max([2,3,4,1]) = 4
So:
winner = 4

Set Coordinator
        self.coordinator = winner


Makes winner new coordinator.



Print Final Coordinator
        print(f"\nProcess {winner} is elected as the new coordinator.")
Output:
Process 4 is elected as the new coordinator.

Main Program
processes = [1, 2, 3, 4]


List of active processes.



ring = RingAlgorithm(processes)


Creates object of RingAlgorithm class.



ring.hold_election(initiator=2)


Process 2 starts election.



Complete Flow
Ring:
1 → 2 → 3 → 4 → back to 1
Election Flow:
2 → 3 → 4 → 1 → back to 2
Election List:
[2,3,4,1]
Highest ID:
4
Coordinator:
4

Final Output
Process 2 starts election.Election message from 2 to 3Election message from 3 to 4Election message from 4 to 1Process 4 is elected as the new coordinator.
