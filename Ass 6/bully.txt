class BullyAlgorithm:
Creates a class named BullyAlgorithm.
A class is like a blueprint to store data and functions together.
    def __init__(self, processes, coordinator=None):
__init__ is a constructor.
It runs automatically when object is created.
processes = list of active processes.
coordinator=None means coordinator can be given manually, otherwise default value used.
        self.processes = processes
Stores process list inside object.

Example:

[1, 2, 3, 5, 6]
        self.coordinator = coordinator or max(processes)
Sets coordinator.
If coordinator is given, use it.
Otherwise choose highest process ID using max().

Example:

max([1,2,3,5,6]) = 6

So coordinator becomes 6.

Function to Check Process Alive
    def is_alive(self, process_id):
Function to check whether process is alive.
        return process_id in self.processes
Returns True if process exists in active list.
Returns False otherwise.

Example:

3 in [1,2,3,5,6]

Output:

True
